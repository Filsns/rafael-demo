# Návrh webu, Sv. Rafael, Vimperk

Nezávazná ukázka od **filsns s.r.o.** pro školní restauraci a apartmány Sv. Rafael
(Střední škola Vimperk), Brantlova 244. Není to oficiální web, stránka je označená
jako návrh a vyloučená z indexace.

Postaveno z veřejných textů, ceníku, ubytovacího řádu a fotek z rafael.stredni-skola.eu.
Statický web bez buildu: `index.html` + `img/`.
